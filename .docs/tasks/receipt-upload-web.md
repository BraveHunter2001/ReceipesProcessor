## 7. Итог

Реализовано. Telegram polling выключен по умолчанию, фоновые OCR/LLM-сервисы продолжают запускаться. Сайт отправляет изображение в `POST /api/receipts/upload`, после чего чек попадает в существующую очередь обработки.

Ограничения: веб-загрузки используют общий `OwnerKey = "web"`, авторизация отсутствует; это временное решение для внутреннего использования. Для текущего multipart endpoint antiforgery временно отключён. После добавления cookie-аутентификации необходимо вернуть antiforgery middleware/токен и удалить `DisableAntiforgery()`. В сборке остаются предупреждения о nullable-моделях PaddleOCR, конфликте версий EF Core и размере frontend bundle.
