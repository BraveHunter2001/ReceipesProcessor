## Правила реестра

- ID не переиспользуются.
- Статусы берутся из [`AGENT_RULES.md`](AGENT_RULES.md).
- Для задачи без анализа использовать `AN-###` со статусом `missing` только временно и сразу создать блокер.
- Если один анализ порождает несколько задач, добавить отдельную строку на каждую связь.
